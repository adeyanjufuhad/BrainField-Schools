# React Bits integration

Reviewed 15 October 2026 using the official [Fade Content documentation](https://reactbits.dev/animations/fade-content), [TypeScript/Tailwind registry source](https://reactbits.dev/r/FadeContent-TS-TW.json) and [React Bits source repository](https://github.com/DavidHDev/react-bits).

The site adapts FadeContent’s simple GSAP fade for school photo/story sections. GSAP is pinned to 3.15.0 in the website package and lockfile. The animation is isolated in a small memoised client component; source content is server-rendered and remains visible without JavaScript. Native IntersectionObserver triggers a single 550ms opacity/12px reveal. Reduced-motion preference disables it, changes to that preference cancel it, and observers/tweens are cleaned up on unmount. Blur, grain masks, disappearing content, heavy backgrounds and perpetual animation are omitted from the school-site adaptation.

The hero slideshow is a custom component with a native range slider and gentle image magnification. React Bits attribution applies to FadeContent; the slideshow and page-wide scroll observer are not copied React Bits components.

The complete React Bits MIT + Commons Clause notice is preserved in [the third-party licence](third-party/REACT-BITS-LICENSE.md). The component is integrated into this school application; it is not offered as a standalone component product. The school’s existing green/red/white palette and readability rules remain in effect.

Update, 15 October 2026: the hero now uses an image-only slideshow, replacing the carousel card, large caption, arrows and dots. Seventeen originals cycle every six seconds with gentle magnification and an inset image-position slider. Hover/focus and background tabs suspend advancement; reduced-motion preference disables autoplay and fading. Credits, source links and uncropped originals remain available in the Gallery.

Current motion update, 15 October 2026: the hero play/pause button is removed at the founder’s request. A compact inset range slider and image counter identify the slideshow and allow direct selection. Images slowly magnify by 4.5% over six seconds; hover/focus pauses advancement and magnification. Source originals remain accessible in the Gallery. Homepage headings, academic blocks, achievement stories, result panels, campus cards, admissions and FAQ content reveal once with a 28px rise and fade. Reduced-motion preference disables autoplay, magnification and reveals while preserving manual image selection.

Update, 17 October 2026: three more React Bits components are integrated under `apps/web/src/components/react-bits/`, each with a source/licence header. **Dot Grid** (registry `DotGrid-TS-TW.json`) sits behind the forest hero and admissions panels in leaf/lime. It renders only during a one-off intro and while a visitor moves or taps, so it never animates on its own, and it respects reduced motion. **Spotlight Card** (`SpotlightCard-TS-TW.json`) wraps the campus cards and the admissions phone panel; it reacts to pointer and keyboard focus only. In both, the props-to-ref sync moved into a layout effect to satisfy the project's React lint rules. **Count Up** (`CountUp-TS-TW.json`) is adapted to count mode without the `motion` dependency. It renders the real value on the server, gives screen readers the final value, and counts only numbers that start below the fold (the 2025 JAMB totals and subject scores).
